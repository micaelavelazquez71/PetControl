# PetControl
Proyecto final de JavaScript: sistema de registro de mascotas utilizando HTML, CSS y JavaScript.
# Funcionalidades
- Registrar mascotas
- Validar datos ingresados
- Mostrar mascotas dinámicamente
- Eliminar mascotas individuales
- Eliminar todas las mascotas
- Contador automático de mascotas registradas
- Registro de fecha y hora
